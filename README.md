# Кабинет New Network — кликабельный прототип

Прототип интерфейса кабинета рекламодателя рекламной сети: запуск кампаний, статистика,
управление площадками, финансы. Площадки и кампании идут под единой нумерацией сети (`NN-…`).

**Демо:** https://hakonprogram.github.io/new-network-cabinet/

Статика без сборки: откройте `index.html` — или отдайте папку любым http-сервером.

```bash
python3 -m http.server 8080
# затем http://127.0.0.1:8080
```

## Что можно потыкать

Интерфейс на английском.

| Раздел | Что работает |
|---|---|
| **Campaigns** | фильтры по статусу и модели; старт/стоп, дублирование, правка и переход в статистику по строке; итоговая строка по выборке |
| **New campaign** | одна страница: формат, пять моделей оплаты, гео со ставками, кривая объёма и прогноз win rate, таргетинг, сетка расписания 7×24, выбор пресета площадок, бюджет, макросы. Запуск создаёт кампанию и уводит в список |
| **Statistics** | период 7/14/30/90 дней, 12 показателей в плитках, четыре графика с ховером (расход, конверсии, прибыль по дням с уходом в минус, win rate), отчёты по площадкам, кампаниям, гео и дням со всеми метриками |
| **Placements** | полный список площадок с результатами, фильтры по категории и вертикали, сортировка по расходу / ROI / конверсиям, блокировка поштучно и пачкой. Отдельный упор — **пресеты**: собрать группу из выделенных строк, применить к кампаниям, переключить whitelist ↔ blacklist |
| **Traffic volumes** | прогноз доступного объёма и win rate по формату, платформе, региону и ставке |
| **Billing** | четыре способа пополнения с разными комиссиями, пополнение реально меняет баланс и историю |
| **Profile** | аккаунт, юр. данные, смена пароля, документы, файлы |
| **Postback** | адрес S2S, макросы с копированием в буфер, инструкция |
| **Notifications** | лента действий робота, фильтры, каналы доставки, порог по балансу |

## Метрики

Везде считаются от одной базы: `Impressions`, `Clicks`, `CTR`, `Conversions`, `CR`, `Cost`,
`Revenue`, `Profit`, `ROI`, `CPA`, `CPM`, `CPC`, `Win rate`. Revenue приходит постбеком —
без него нет ни ROI, ни моделей за результат.

## Модели оплаты

`CPA` (платный тест) · `Pure CPA` (тест за счёт сети) · `CPM` · `Smart CPM` (аукцион второй цены) · `CPC`

## Данные

Все цифры — **демонстрационные образцы**, а не реальные показатели: комиссии способов оплаты,
минимальные ставки, рекомендуемые ставки по гео и адрес постбека нужно заменить настоящими.

Состояние (созданные кампании, пресеты, блокировки площадок, пополнения, прочитанные
уведомления) хранится в `localStorage` браузера и переживает перезагрузку.
Сбросить — Support → Reset demo data.

## Структура

```
index.html          каркас страницы
styles.css          токены и все компоненты
js/ui.js            иконки, форматирование, производные метрики, ряды для графиков
js/data.js          демо-данные
js/store.js         состояние + localStorage
js/app.js           маршруты, сайдбар, шапка, делегирование событий
js/screens/*.js     по файлу на раздел
```

Маршруты — на хэшах: `#/campaigns`, `#/campaigns/new`, `#/stats`, `#/zones`, `#/volumes`,
`#/payments`, `#/profile`, `#/postback`, `#/notifications`.

Зависимостей нет; из внешнего — только шрифты Google (Archivo, JetBrains Mono).
Без сети интерфейс работает, шрифт подменяется системным.
