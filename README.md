# Кабинет New Network — кликабельный прототип

Прототип кабинета рекламодателя для рекламной сети, которая даёт **один кабинет поверх восьми
сторонних источников трафика**. Рекламодатель нигде не видит, из какой сети пришёл показ:
кампании и площадки идут под нумерацией сети (`NN-…`).

Статика без сборки: откройте `index.html` — или отдайте папку любым http-сервером.

```bash
python3 -m http.server 8080
# затем http://127.0.0.1:8080
```

## Что можно потыкать

| Раздел | Что работает |
|---|---|
| **Кампании** | фильтры по статусу и модели; старт/стоп, дублирование, правка и переход в статистику по строке |
| **Создание кампании** | одна страница: формат, пять моделей оплаты, гео со ставками, кривая объёма от ставки, таргетинг, сетка расписания 7×24, списки площадок, бюджет, макросы. Запуск создаёт кампанию и уводит в список |
| **Статистика** | период 7/14/30/90 дней, два графика с ховером (расход и конверсии — разные шкалы, поэтому разные графики), отчёты по площадкам, кампаниям, гео и дням |
| **Площадки** | блокировка и масштабирование по номерам сети, группы, разделение «отключил робот» и «заблокировал рекламодатель» |
| **Объёмы трафика** | прогноз доступного объёма по формату, платформе, региону и ставке |
| **Платежи** | четыре способа пополнения с разными комиссиями, пополнение реально меняет баланс и историю |
| **Профиль** | аккаунт, юр. данные, смена пароля, документы, файлы |
| **Постбек** | адрес S2S, макросы с копированием в буфер, инструкция |
| **Уведомления** | лента действий робота, фильтры, каналы доставки, порог по балансу |

## Модели оплаты

`CPA` (платный тест) · `Pure CPA` (тест за счёт сети) · `CPM` · `Smart CPM` (аукцион второй цены) · `CPC`

## Данные

Все цифры — **демонстрационные образцы**, а не реальные показатели: комиссии способов оплаты,
минимальные ставки, рекомендуемые ставки по гео и адрес постбека нужно заменить настоящими.

Состояние (созданные кампании, блокировки площадок, пополнения, прочитанные уведомления)
хранится в `localStorage` браузера и переживает перезагрузку. Сбросить — «Поддержка» →
«Сбросить демо-данные».

## Структура

```
index.html          каркас страницы
styles.css          токены и все компоненты
js/ui.js            иконки, форматирование, генерация рядов для графиков
js/data.js          демо-данные
js/store.js         состояние + localStorage
js/app.js           маршруты, сайдбар, шапка, делегирование событий
js/screens/*.js     по файлу на раздел
```

Маршруты — на хэшах: `#/campaigns`, `#/campaigns/new`, `#/stats`, `#/zones`, `#/volumes`,
`#/payments`, `#/profile`, `#/postback`, `#/notifications`.

Зависимостей нет; из внешнего — только шрифты Google (Archivo, JetBrains Mono).
Без сети интерфейс работает, шрифт подменяется системным.
